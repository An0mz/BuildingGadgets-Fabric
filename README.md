# Welcome to st'ructure tools continued!

`st'ructure tools continued` aims to make building a little easier. At this time there are `four` tools, which will help you build your st'ructures. Alternatively, watch the following mod spotlight for instructions!

## Credit

An especially big thanks to all of our [contributors](https://github.com/ProjectET/BuildingGadgets-Fabric/graphs/contributors).
This mod is a port of [DireWolf20's Building Gadgets](https://github.com/Direwolf20-MC/BuildingGadgets) for Fabric, so credit to him for the Forge mod in the first place :)
Big thanks for the work of [ProjectET](https://github.com/St-ructure-Mods/BuildingGadgets-Fabric) for the port!

## A notice on naming

This mod is named `st'ructure tools continued`, but internally this mod should still be referenced as building gadgets for parity reasons

## Reason for the continued

This mod has not been updated for the last 3 years and as such I decided to make it compatible with newer version.
